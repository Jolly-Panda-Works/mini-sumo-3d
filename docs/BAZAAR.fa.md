# نسخه‌ی کافه بازار

نسخه‌ی کافه بازار همان بازی است، با این تفاوت‌ها:

- **خرید سکه با پرداخت درون‌برنامه‌ای بازار** (کتابخانه‌ی رسمی Poolakey 2.2.0)
- بدون Google Play Games (ورود با گوگل در پروفایل نمایش داده نمی‌شود)

کد هر دو نسخه یکی است. نسخه‌ی بازار فقط با تنظیمات ساخت فعال می‌شود: `VITE_STORE=bazaar` و اسکریپت `apps/mobile/scripts/bazaar.mjs`.

## ساخت شاخه (یک بار)

```cmd
git checkout main
git pull
git checkout -b bazaar
git push -u origin bazaar
```

هر push روی شاخه‌ی `bazaar` نسخه‌ی بازار را می‌سازد (**Actions ← Bazaar**) و یک Release با تگ `bazaar-vX.Y.Z` منتشر می‌کند.

## به‌روز نگه داشتن

تغییرات همیشه روی `main` انجام می‌شود. برای ساخت نسخه‌ی جدید بازار:

```cmd
git checkout bazaar
git merge main
git push
git checkout main
```

شماره‌ی نسخه و versionCode از `package.json` می‌آید، پس با نسخه‌ی گوگل‌پلی یکسان است.

## تنظیمات

| فایل | محتوا |
|---|---|
| `apps/mobile/bazaar.config.json` | کلید RSA پرداخت درون‌برنامه‌ای، نسخه‌ی Poolakey و Kotlin |
| `apps/client/src/network/bazaarProducts.ts` | شناسه‌ی محصولات بازار برای هر بسته‌ی سکه |

کلید RSA **عمومی** است و فقط برای تأیید امضای خریدها روی گوشی استفاده می‌شود. ثبت آن در مخزن مشکلی ندارد. اگر خواستید جای دیگری نگه دارید، متغیر `BAZAAR_RSA_KEY` در تنظیمات مخزن مقدار فایل را جایگزین می‌کند.

## روند خرید

۱. بازیکن روی **BUY** یک بسته می‌زند. پنجره‌ی پرداخت بازار باز می‌شود و قیمت را خود بازار نشان می‌دهد.
۲. بعد از پرداخت موفق، سکه‌ها به کیف پول گوشی اضافه می‌شوند. هر خرید با شناسه‌ی پرداختش **فقط یک بار** حساب می‌شود.
۳. خرید «مصرف» (consume) می‌شود تا همان بسته دوباره قابل خرید باشد.
۴. اگر برنامه بین پرداخت و افزودن سکه بسته شود، دفعه‌ی بعد که فروشگاه باز شود، خرید ناتمام پیدا و سکه‌اش اضافه می‌شود.

> سکه‌ها روی خود گوشی نگه داشته می‌شوند. برای جلوگیری کامل از تقلب در آینده، تأیید خرید باید روی سرور با API بازار انجام شود (وقتی سرور راه‌اندازی شد).

## امضا

همان secretهای `ANDROID_KEYSTORE_*` نسخه‌ی گوگل‌پلی استفاده می‌شوند. اگر تنظیم نشده باشند، فقط APK دیباگ ساخته می‌شود.


## خرید آنلاین (بررسی خرید روی سرور)

وقتی بازی به سرور وصل است، کیف پول بازیکن روی سرور است. برای همین خرید از کافه بازار این مسیر را طی می‌کند:

۱. بازیکن در کافه بازار پرداخت می‌کند و اپ یک **توکن خرید** می‌گیرد.
۲. اپ توکن را به `POST /api/purchases/bazaar` روی سرور می‌فرستد.
۳. سرور با **Developer API** کافه بازار بررسی می‌کند که خرید **واقعی** است، **مصرف نشده** و مربوط به **همان محصول** است.
۴. سرور سکه‌ها را **یک بار** اضافه می‌کند. هر توکن فقط یک بار، و فقط برای اولین حسابی که آن را بفرستد، پذیرفته می‌شود.
۵. فقط بعد از تأیید سرور، اپ خرید را در کافه بازار **مصرف** می‌کند تا دوباره قابل خرید باشد.

اگر وسط کار مشکلی پیش بیاید (اینترنت قطع شود، سرور یا کافه بازار در دسترس نباشد)، خرید **مصرف نمی‌شود** و دفعه‌ی بعد که بازی وصل شود یا فروشگاه باز شود، دوباره فرستاده می‌شود. هیچ پرداختی گم نمی‌شود.

### راه‌اندازی

۱. روی کامپیوتر، در پوشه‌ی پروژه: `tools\bazaar-api-setup.cmd` (کلیدها را از کافه بازار می‌گیرد).
۲. روی سرور، در پوشه‌ی پروژه: `git pull` و بعد `bash tools/server-bazaar-setup.sh` (کلیدها را در `.env` سرور می‌گذارد و بازی را دوباره اجرا می‌کند).
۳. در لاگ سرور (`docker compose logs web`) باید این خط را ببینید:
   `[bazaar] purchase verification on (com.jollypanda.mini_sumo)`

تا وقتی کلیدها روی سرور نباشند، فروشگاه در حالت آنلاین **COMING SOON** نشان می‌دهد و هیچ پولی گرفته نمی‌شود. در حالت آفلاین، خرید مثل قبل روی خود دستگاه ثبت می‌شود.

شناسه‌ی محصولات حالا در `packages/shared/src/economy.ts` (`BAZAAR_PRODUCTS`) است تا اپ و سرور از یک لیست استفاده کنند.
